# 🎯 Use Case Classification Framework (UCCF)

## Overview

This folder contains NovaTech's **Use Case Classification Framework (UCCF)** — the "front door" to the entire AI governance program. The UCCF ensures that every AI use case is classified according to its risk profile, triggering the appropriate level of governance, documentation, and oversight.
