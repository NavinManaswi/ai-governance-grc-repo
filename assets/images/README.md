# 📸 Images

## 📂 Contents

| File | Description | Usage |
|------|-------------|-------|
| `portfolio-banner.png` | Professional banner image for GitHub and LinkedIn | README header |
| `grc-pyramid.png` | 4-Layer GRC Pyramid diagram | Articles, presentations |

## 🎨 Where to Create These Images

- **Banner Image:** Canva, Adobe Express, or hire a designer on Fiverr/Upwork
- **Diagrams:** Lucidchart, Draw.io (free), Miro, or PowerPoint
